# DepthBridge Studio 界面设计规范

本规范记录用户在 2026-10-29 确认的设计要求，供后续实现与验收使用。

## 用户要求

1. 整体重新设计工作台页面，统一布局、视觉层级、组件和交互。
2. 检查现有流程中的不合理设计；“真机准备”退出主导航，帮助按需查看。
3. 真机操作优先；离线示例作为明确选择的辅助入口，避免和真实测量混淆。
4. 整个页面增加动态效果、交互反馈和粒子动态效果。
5. 动效可关闭，遵循系统减少动态效果设置；图像选点和三维操作保持准确。
6. README 与页面同步，使用新版真实截图、专业文字、系统架构图和工作机制图。
7. 功能、交互、不同窗口尺寸及文档验证通过后，推送 GitHub。

## 实现准则

用户随后明确要求配色、设计和布局全部更换，并指定参考 MUUUUU 的 dynamic-motion 案例。先提交效果图，经用户确认后实施。最终确认方案为蓝白配色、大字号标题、黑色窄工具轨、RGB/点云双视窗和独立测量面板；以 [确认效果图](design/approved-concept.png) 为视觉基准。

- 三步主流程：采集与定位 → 坐标标定 → 误差验证。
- 状态明确区分：待连接、连接中、实时预览、暂停测量、文件回放、示例模式。
- 未连接时使用空状态；断开相机不会切入合成画面。
- 帮助、会话工具与视觉偏好使用辅助面板。
- 采用中性白、石墨黑和群青蓝；统一 SVG 图标、大字号中文标题、16 px 操作文字、等宽测量数值和清晰对比。
- 动效服务于状态变化，粒子层不拦截点击；在后台暂停，控制渲染开销。
- 测量画布保持源图纵横比；动画不改变像素映射。
- 数据源分别保留会话，人工输入、原始 RGB-D 和标定约定保持可追溯。

## 文档交付

- 页面截图与当前版本一致，说明真实采集与合成示例的来源。
- 架构图展示相机适配、数据处理、API、会话与浏览器的职责。
- 坐标转换图展示像素/深度、相机 XYZ、基座变换与独立验证。
- 采集机制图解释预览、暂停、显示帧选点与导出。

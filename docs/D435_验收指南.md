# 固定 D435 真机验收

首测目标：验证 D435 数据、像素到三维位置、固定相机坐标标定与独立测量误差。工具不发送机械臂动作。

## 准备

- Windows + Python 3.12 x64，D435 与 USB 3 数据线。
- 相机固定在刚性支架，确保目标在有效视野内；先用普通哑光平面测试深度。
- 机械臂使用正确基座坐标系，TCP 已标定。机械臂示教器显示的 TCP 位置要对应实际测量点。
- 选用可明确复现的物理特征，例如标记点、标定板角点或有明确尖点的标记件。
- 要测的视觉表面点与 TCP 接触点必须是同一点；不要将图像上的物体顶部与机械臂测到的桌面位置配对。

## 1. 启动与连接

```powershell
.\setup.ps1
.\start.ps1
```

已有项目环境可直接 `.\start.ps1`。必要时执行 `.\.venv\Scripts\python.exe -m depthbridge --devices`。

1. 关闭 Viewer 等占用设备的程序。
2. 点击右上角“连接相机”，选择设备，记录序列号，点击“连接 D435”。需要重新检测时点击刷新设备按钮。
3. 横幅应切为真实相机，坐标变换应为“尚未标定”。
4. 如果当前进程之前已经为同一相机标定，程序会恢复该设备的会话。相机位置变化后请重新采集，或重启后开始新会话。

## 2. 检查原始测量

1. 查看 RGB、深度、叠加图，检查目标边缘是否对应。
2. 点选平面内部，检查相机 Z 与实际安装距离是否处于合理范围。
3. 同一点多次采集，观察波动。记录 RGB-D 帧，保留问题复现数据。
4. 深度图按当前帧有效深度的 2%–98% 分位自动着色，当前范围显示在图像上。着色会在范围两端饱和，原始深度和测量值不会截断。
5. 默认取 5×5 邻域有效深度的中值，并沿点击像素射线生成点。精确特征/物体边缘建议半径 0，避免混合前景背景。
6. 中心像素没有深度时会拒绝测量，不用邻近背景填充出看似有效的位置。

## 3. 采集同名三维点

每个点的操作：

1. 相机、目标与场景静止，点击“采集一帧”。
2. 在清晰物理特征上选点。“实时预览”会在点击后暂停，选点对应画面中的那一帧。
3. 在机械臂端测得同一点的 TCP 基座坐标。机械臂挡住相机时，先保存无遮挡画面，再测量，期间不要移动目标或相机。
4. 点击“记录标定点”，填入基座 X/Y/Z，**单位 mm**。
5. 添加标签，再点“添加对应点”。

至少 4 个非共线点。建议 8–12 点覆盖左/右/前/后，另选不同高度的标记件。平面点可以求刚体变换，但只在一个平面测量不能充分检查高度方向的误差。

## 4. 求解与验证

1. 点击“求解固定相机变换”。界面矩阵为 `T_base_from_camera`，平移是米。
2. 拟合残差用于检查采集一致性。异常点应回看其像素、深度与实测坐标，不凭一个总指标判断准确。
3. 选择 3–5 个**未参与标定的新物理点**，用途设为“独立验证”。
4. 在“误差验证”查看逐点三维欧氏误差、RMS、最大值。
5. 按目标尺寸、夹爪开口与任务要求判断是否可用。本版不预设能达到某个实机精度。

把同一个标定点再次点击、换个名字加入验证，不能作为真正的独立验证；程序能区分记录用途，物理点是否独立需要操作者保证。

## 5. 保存

- **标定 JSON**：变换方向、单位、数据源序列号、标定和验证摘要。
- **会话 JSON**：全部选点、实测对应点、手眼观测、变换与参数。
- **RGB-D ZIP**：当前完整画面、深度、相机内参和 SDK XYZ。
- **CSV**：对应点和当前变换下的误差。
- **PLY**：相机光学坐标系下的降采样彩色点云，单位米。

恢复时先连接同一设备，再导入会话或标定。更换相机、移动支架或改变安装关系后重新标定。

## 常见问题

- **无设备**：换 USB 数据线/接口、检查设备管理器与占用程序，先看官方 Viewer 能否正常输出深度。
- **整体平移偏差**：核对 TCP、视觉与接触点是否相同、矩阵平移单位、机器人坐标系。
- **位置越远误差越大**：核对内参和对齐；重新采集覆盖范围更大的对应点，检查深度系统误差。
- **只在边缘抓偏**：检查选点邻域混入背景，尝试单像素采样和更清晰标记。
- **相机移动后误差变大**：原固定变换已失效，重新标定。
- **端口被占用**：`.\start.ps1 -Port 8766`。

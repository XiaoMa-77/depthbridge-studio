## 求解验证

- 从已知旋转和平移生成对应点，检查刚体拟合恢复原矩阵。
- 验证平面非共线点可求解，共线/过于集中点拒绝。
- 从已知坐标链生成 18 组机器人位姿及标定板观测，验证两种安装方式的手眼矩阵方向。
- 手眼缺少足够旋转激励时拒绝求解。
- 末端相机验证使用采集时机器人位姿，不随当前机器人位姿变化而重写历史测量。
- RGB-D ZIP 往返保存、毫米深度比例、SDK 点图、无效深度和未对齐数据处理均有测试。
- 真实来源不会继承合成变换；过期帧选点返回明确错误。

## 验证中修正的问题

1. OpenCV 5 的接口变化导致手眼函数不可用，依赖限定到已验证的 OpenCV 4.x。
2. 缩放图片的 CSS `object-fit` 会影响坐标映射，改为保持源图纵横比。
3. Windows shell 启动器可能留下子服务，改为直接管理服务进程并在退出时清理；浏览器验收使用独立临时端口。
4. 相机连接失败时不隐式切换成示例画面冒充真实数据。
5. 合成真值填写使用固定示例参考变换，不随用户修改的当前矩阵变化。

当前测试依赖有一条 Starlette 对 httpx TestClient 的弃用提示，不影响上述结果。

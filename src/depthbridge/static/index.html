HELP / GET STARTED

从连接到验证

01

连接与采集

使用 USB 3 连接 D435，选择设备并连接。开启实时预览，或采集一帧。

02

点选与标定

点击画面会暂停预览并锁定显示帧。记录同一物理点的实测基座 XYZ，建立对应关系。

03

独立验证

至少 4 个非共线标定点求解变换，再用未参与拟合的新物理点检查误差。

连接遇到问题

关闭占用相机的 Viewer，检查 USB 数据线与驱动。终端执行 depthbridge --devices 检测设备。SDK 安装：python -m pip install -e ".[realsense]"。

坐标、单位与测量

相机 X 向右、Y 向下、Z 向前。界面显示 mm，矩阵平移使用 m。深度 Z 是光轴分量；预接近点沿基座 +Z 偏移，运动执行需结合实际机械臂验证。

保存和恢复工作

通过“数据与示例”保存会话。恢复时先连接相同设备，再导入 JSON。完整图像另存 RGB-D 帧；调整相机安装位置后重新标定。

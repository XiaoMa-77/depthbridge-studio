明天：连接固定支架上的 D435

先确认数据，再求解坐标关系，最后做独立验证。

INTEL REALSENSE D435
连接前
  1. 将 D435 固定，测试期间保持位置与角度不变。
  2. 使用 USB 3 数据线，关闭 RealSense Viewer 等占用相机的程序。
  3. 项目虚拟环境安装 RealSense 扩展：python -m pip install -e ".[realsense]"
  4. 点击左侧“检测设备”，选择序列号，然后“连接 D435”。
RealSense 官方 SDK ↗
开始测量
  1. 检查 RGB、深度和叠加视图，确认物体边缘对应。
  2. 在哑光平面上选点，检查深度是否合理。物体边缘用单像素采样。
  3. 相机和目标静止时，采集至少 4 组同名点，推荐 8–12 组。
  4. 填入已标定 TCP 测得的同一点基座坐标，单位 mm。
  5. 求解后留出新的物理点，记录为“独立验证”。
  6. 导出会话、标定、CSV 和必要的 RGB-D 帧。
排查提示

检测不到相机

检查 USB、驱动和进程占用。终端运行 depthbridge --devices 获取检测结果。

深度缺失或跳动

检查距离、反光、透明材质和照明；先用普通纸面确认，再测目标物体。

坐标明显错位

核对基座/工具坐标系、mm 与 m、矩阵方向，以及相机是否被移动。

保存与恢复

退出前导出会话；恢复时先连接同一序列号设备，再导入会话。改变安装位置后重新标定。

会话文件

会话包含选点、对应点、变换及观测数据。完整图像请另外保存 RGB-D 帧。当前工作空间在进程内保留，退出前导出。

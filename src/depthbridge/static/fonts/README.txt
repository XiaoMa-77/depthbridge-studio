DepthBridge offline typography

Modified, renamed WOFF2 subsets of Noto Sans SC (DepthBridge Sans),
Manrope (DepthBridge Display), IBM Plex Mono Regular (DepthBridge Mono).
CSS aliases: DBSans / DBDisplay / DBMono.

Sources: https://github.com/google/fonts/tree/main/ofl/
Directories: notosanssc, manrope, ibmplexmono. Retrieved 2026-10-29.
Original copyright and OFL notices remain in each font and the adjoining
OFL-*.txt files. Subsets retain Latin text and the application's UI glyphs;
other characters use the operating system fallback font.

These assets are served locally. No runtime font network requests.
